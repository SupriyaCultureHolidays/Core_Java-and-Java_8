# Lecture 01 — Assignment

থিওরি-only, কোনো কোড লাগবে না। [SpringBoot.html](../../../SpringBoot.html)-এর sec-1 ও sec-4-এর শেষে
থাকা "অনুশীলন প্রশ্ন" নিজের ভাষায় লিখে answer করো:

1. Client ও Server-এর সংজ্ঞা নিজের ভাষায় লেখো, এবং একটা উদাহরণ দাও যেখানে একটা server
   নিজেই আরেকটা server-এর client হয়ে যায়।
2. HTTP request-এর চারটা অংশ কী কী? Servlet Container (যেমন Tomcat) কোন কোন কাজ
   ডেভেলপারের হাত থেকে সরিয়ে নেয়?
3. Spring Boot, Spring MVC-কে replace করেনি কেন? এবং Spring Data JPA → Hibernate →
   JDBC — এই চেইনটা নিজের ভাষায় ব্যাখ্যা করো।

এই লেকচারে হাতে-কলমে কোনো কোড নেই বলে আলাদা কোনো scaffold ফাইল নেই — উদ্দেশ্য শুধু concept
ঝালাই করা।
